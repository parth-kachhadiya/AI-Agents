Topic-03 : The Agent Loop

🔷 The big idea
    • An agent is a `while` loop around an LLM call. LLM decides, your code acts, the result goes back, and LLM decides again. There is no magic beyond it.

🔷 Visual Loop

                        +-------------------+
                        |  1. User Request  |
                        +-------------------+
                                  ⬇
                    +-----------------------------+
                    |  2. LLM Decides what to do  | 
                    +-----------------------------+
                                  ⬇
                   +-------------------------------+
                   |  3. Did LLM asked for tool ?  |
                   +-------------------------------+
                      ⬇ YES                     ⬇ NO 
                   +-----------+            +-----------+               
                   | 4.Execute |            | 6. Final  |
                   |    Tool   |            |  Answer   |
                   +-----------+            +-----------+               
                       ⬇                        ⬇
                   +-----------+              LOOP_END          
                   | 5. Return |
                   |  Result   |
                   +-----------+ 
                      ⬇
                    BACK_TO_STEP_2
